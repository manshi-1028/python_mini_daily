
# Day 80 — Capstone Project: House Prices 🏠📊

## 100 Days of Code — Python Bootcamp

### 📚 What I Learned

Day 80 is the first major **capstone project** of the Data Science section.

The goal is to take everything learned so far and apply it to a real-world machine learning problem:

> **Predict the sale price of a house based on its features.**

The project uses the **Kaggle House Prices: Advanced Regression Techniques** dataset, which contains information about residential properties and their sale prices. :contentReference[oaicite:0]{index=0}

Unlike previous days, the project is designed to be completed with much less step-by-step guidance. It combines:

- Data cleaning
- Exploratory Data Analysis
- Feature engineering
- Data preprocessing
- Regression
- Model training
- Model evaluation
- Predictions
