# 🚴 Pixela Cycling Tracker

A simple Python project that uses the **Pixela API** to track daily cycling distance and visualize it on a contribution-style graph.

The project sends cycling data to Pixela and records the distance for the current day.

## 🚀 Features

- 📊 Track daily cycling distance
- 🚴 Record cycling activity in kilometers
- 📅 Automatically uses the current date
- 🌐 Uses the Pixela REST API
- 🔐 Keeps API credentials secure using environment variables
- 📈 Visualize cycling activity through a Pixela graph

## 🛠️ Technologies Used

- Python
- Requests
- python-dotenv
- Pixela API
