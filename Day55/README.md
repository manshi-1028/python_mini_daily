# Day 55 - Higher Lower Game

A Python web application built with Flask that creates a Higher or Lower number guessing game.

## What This Project Does

The program:

1. Starts a Flask web server.
2. Generates a random number between 0 and 9.
3. Allows the user to enter a guess through the URL.
4. Compares the user's guess with the correct answer.
5. Displays whether the guess is too high, too low, or correct.

## Technologies Used

- Python
- Flask
- HTML
- Python Decorators
