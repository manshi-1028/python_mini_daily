# 100 Movies You Must Watch

A Python web scraping project built using BeautifulSoup.

## What This Project Does

This program:

1. Sends a request to a movie-ranking website.
2. Uses BeautifulSoup to parse the HTML.
3. Finds the movie titles.
4. Reverses their order so the movies are listed from #1 to #100.
5. Saves the movie titles into `movies.txt`.

## Technologies Used

- Python
- Requests
- BeautifulSoup
