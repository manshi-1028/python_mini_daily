## What I Learned

* Basics of Web Design
* UI vs UX
* Color Theory
* Color Schemes
* Typography
* Visual Hierarchy
* User Interface (UI) Design
* User Experience (UX) Design
* Whitespace and Alignment
* Creating effective and user-friendly websites

## Topics Covered

### 🎨 Color Theory

* Complementary colors
* Analogous colors
* Triadic colors
* Warm and cool colors
* Contrast

### ✍️ Typography

* Serif vs Sans-serif
* Font size and weight
* Font hierarchy
* Choosing readable fonts

### 👀 Visual Hierarchy

Using:

* Size
* Color
* Contrast
* Position
* Spacing

to guide the user's attention.

### 🖥️ UI Design

Focuses on how a website **looks and interacts** with the user.

### 🧭 UX Design

Focuses on making the website **easy, useful, and enjoyable to use**.

## Key Principles

* Keep designs simple.
* Use consistent colors and fonts.
* Use whitespace effectively.
* Make important elements stand out.
* Keep navigation clear.
* Design for different screen sizes.

## Technologies

This day focused mainly on **design concepts rather than coding**.

## Learning Outcome

Learned the basic principles needed to create websites that are **visually appealing, clear, consistent, and user-friendly**.
