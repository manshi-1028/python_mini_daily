# Day 51 - Internet Speed Twitter Complaint Bot

A Python automation project that checks the user's internet speed and automatically posts a complaint on Twitter/X when the actual speed is lower than the internet service provider's promised speed.

## What This Project Does

The program:

1. Opens an internet speed testing website.
2. Measures the current download speed.
3. Measures the current upload speed.
4. Compares the actual speeds with the promised speeds.
5. Logs into Twitter/X.
6. Posts a complaint if the internet speed is below the promised speed.

## Technologies Used

- Python
- Selenium
- Web Automation
- Internet Speed Test
- Twitter/X
