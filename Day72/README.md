
# Day 72 — Data Visualisation with Matplotlib: Programming Languages 📊

## 100 Days of Code — Python Bootcamp

### 📚 What I Learned

Day 72 focused on **data visualisation using Pandas and Matplotlib**.

The project analyzes programming language popularity using data from Stack Overflow and visualizes how the popularity of different programming languages has changed over time.

## 🎯 Project Goal

The goal was to take raw programming-language data and:

- Explore the dataset
- Clean and prepare the data
- Convert dates into a usable format
- Manipulate the data using Pandas
- Create pivot tables
- Visualize programming-language popularity
- Create multi-line charts
- Smooth time-series data
