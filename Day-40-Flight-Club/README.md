# ✈️ Day 40 - Flight Club

## 100 Days of Python

This project is part of Day 40 of the **100 Days of Code: The Complete Python Pro Bootcamp**.

The project extends the Flight Deal Finder into a **Flight Club** system where customers can submit their details and receive flight deal notifications by email.

---

## 🚀 Features

- Retrieve destination information from Google Sheets using Sheety
- Find missing IATA airport codes
- Search for flight offers using the Amadeus API
- Retrieve customer email addresses
- Send flight deal notifications by email
- Automate the process using Python

---

## 🛠️ Technologies Used

- Python
- Amadeus API
- Sheety API
- Google Sheets
- Requests
- SMTP
- EmailMessage
