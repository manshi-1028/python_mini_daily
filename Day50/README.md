# Day 50 - Internet Speed Twitter Complaint Bot

A Python automation project that checks the internet speed provided by an internet service provider and automatically posts a complaint on Twitter/X if the actual speed is lower than the promised speed.

## What This Project Does

The program:

1. Opens an internet speed testing website.
2. Measures the current download and upload speeds.
3. Compares the actual speeds with the promised speeds.
4. Logs into Twitter/X.
5. Posts a complaint if the internet speed is significantly lower than expected.

## Technologies Used

- Python
- Selenium
- Web Automation
- Twitter/X
- Internet Speed Test
