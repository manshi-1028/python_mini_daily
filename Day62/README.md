# Day 62 - Coffee & WiFi

A Flask web application that displays information about cafés and allows users to add new café locations using a form.

## Coffee & Wifi Project
![day62](https://user-images.githubusercontent.com/98851253/161461262-b6962031-b23d-4bdf-8afa-e30a2892f387.gif)


## What This Project Does

The application:

1. Displays a list of cafés.
2. Shows information about each café.
3. Uses Flask to handle different pages.
4. Uses Flask-WTF and WTForms to create forms.
5. Uses Bootstrap to style the website.
6. Allows users to submit new café information.
7. Stores café information in a CSV file.

## Technologies Used

- Python
- Flask
- Flask-WTF
- WTForms
- Bootstrap
- Bootstrap-Flask
- Jinja
- HTML
- CSS
- CSV
